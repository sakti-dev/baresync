# Create Sync Client

`createSyncClient` builds a `SyncClient` instance that your app uses for every sync operation. You typically create one client per scope and hold it in a React context. By default it calls the Baresync Tauri plugin commands under the `plugin:baresync|...` namespace.

## Import

```ts
import { createSyncClient } from "baresync/tauri";
```

## Config

```ts
const client = createSyncClient({
  apiUrl: "http://127.0.0.1:3001",
  encoding: "json",
  scopeId: "outlet-1",
  invoke,
});
```

| Field | Type | Required | Description |
|---|---|---|---|
| `apiUrl` | `string` | Yes | Your server's base URL (used by the Tauri plugin for HTTP requests) |
| `encoding` | `"json"` | Yes | Wire encoding for sync payloads |
| `scopeId` | `string` | Yes | The scope this client syncs under (must match a scope in your sync contract) |
| `commands` | `SyncClientCommands` | No | Optional command-name overrides for legacy app-local wrappers |
| `invoke` | `(cmd, args?) => Promise<unknown>` | No | Tauri IPC function. Defaults to a stub that throws outside Tauri runtime |

### apiUrl

The plugin uses this URL when making HTTP requests to your server. It is not used by the JS client directly.

### encoding

Set to `"json"`. Baresync currently uses JSON-only sync payloads.

### scopeId

Must match one of the scope IDs in your `sync.config.ts`. All sync commands from this client will use this scope.

### invoke

In a Tauri app, pass `invoke` from `@tauri-apps/api/core`:

```ts
import { invoke } from "@tauri-apps/api/core";

const client = createSyncClient({
  apiUrl: "http://127.0.0.1:3001",
  encoding: "json",
  scopeId: "outlet-1",
  invoke,
});
```

If you omit `invoke`, the client throws with a descriptive error when you call any command. This is intentional — it prevents silent failures if the client is accidentally used outside a Tauri window.

If you omit `commands`, the client uses the plugin namespace defaults:

```txt
plugin:baresync|sync_now
plugin:baresync|sync_push
plugin:baresync|sync_pull
plugin:baresync|sync_full_resync
plugin:baresync|get_sync_local_state
plugin:baresync|start_polling
plugin:baresync|stop_polling
plugin:baresync|pause_polling
plugin:baresync|resume_polling
plugin:baresync|get_polling_status
```

## Return type

`createSyncClient` returns a `SyncClient` object with these methods:

```ts
interface SyncClient {
  enqueueChange<TTx>(tx: TTx, options: LocalChangeOptions): Promise<void>;
  fullResync(): Promise<unknown>;
  getPollingStatus(): Promise<PollingStatus>;
  getState(): Promise<SyncLocalState>;
  pausePolling(): Promise<unknown>;
  pull(): Promise<unknown>;
  push(): Promise<unknown>;
  resumePolling(): Promise<unknown>;
  startPolling(): Promise<unknown>;
  stopPolling(): Promise<unknown>;
  syncNow(): Promise<unknown>;
  writeLocalChange<TTx>(tx: TTx, options: WriteLocalChangeOptions<TTx>): Promise<void>;
  writeTransaction<TTx, TResult>(db: SyncDatabase<TTx>, callback: (tx: TTx) => Promise<TResult>): Promise<TResult>;
}
```

## Singleton pattern

Create the client once and share it via React context:

```tsx
import { createContext, useState, type ReactNode } from "react";
import { createSyncClient, type SyncClient } from "baresync/tauri";
import { invoke } from "@tauri-apps/api/core";

const SyncClientContext = createContext<SyncClient | null>(null);

export function SyncClientProvider({ children }: { children: ReactNode }) {
  const [client] = useState(() =>
    createSyncClient({
      apiUrl: "http://127.0.0.1:3001",
      encoding: "json",
      scopeId: "outlet-1",
      invoke,
    })
  );

  return (
    <SyncClientContext.Provider value={client}>
      {children}
    </SyncClientContext.Provider>
  );
}

export function useSyncClient(): SyncClient {
  const client = useContext(SyncClientContext);
  if (!client) {
    throw new Error("useSyncClient must be used within SyncClientProvider");
  }
  return client;
}
```

`useState` with an initializer ensures the client is created once per mount.

## Common mistakes

- **Creating a new client on every render.** Use `useState` or `useRef` with an initializer.
- **Passing the wrong scopeId.** The scope must match what your server expects. Check `sync.config.ts`.
- **Forgetting to pass `invoke`.** The default stub only works in tests with a mock. In a real app, always pass Tauri's `invoke`.
