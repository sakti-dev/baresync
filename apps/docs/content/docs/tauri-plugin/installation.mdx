# Installation

Add the runtime crates to your `Cargo.toml`. You only need `baresync-core` in `[build-dependencies]` if you are embedding migrations from a `build.rs` script.

## Cargo.toml

```toml
[dependencies]
baresync-core = { version = "0.1.0" }
tauri-plugin-baresync = { version = "0.1.0" }
tauri = { version = "2", features = [] }

[build-dependencies]
tauri-build = { version = "2", features = [] }
```

## What you need next

After adding the dependencies, you need:

1. A `lib.rs` that configures the builder and registers commands — see [Builder](/docs/tauri-plugin/builder) and [Commands](/docs/tauri-plugin/commands)
2. `.sql` migration files in a `migrations/` directory if you are using `migrations_path(...)` — see [Migrations](/docs/tauri-plugin/migrations)
3. A `build.rs` only if you are embedding migrations — see [Migrations](/docs/tauri-plugin/migrations)

Next: [Builder](/docs/tauri-plugin/builder).
