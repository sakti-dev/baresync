# Quickstart

Build a Tauri app that syncs local SQLite rows with your own backend.

Follow these steps in order:

1. [Set up the project](/docs/getting-started/project-setup) — monorepo, Tauri app, Hono server.
2. [Create the sync contract](/docs/getting-started/create-sync-contract) — shared schemas and generated artifacts.
3. [Register the Tauri plugin](/docs/getting-started/register-tauri-plugin) — Rust plugin, migrations, commands.
4. [Set up the local database](/docs/getting-started/set-up-local-database) — Drizzle proxy and table registry.
5. [Write local changes](/docs/getting-started/write-local-changes) — outbox-enqueued inserts and updates.
6. [Add server routes](/docs/getting-started/add-server-routes) — push, pull, and status handlers.
7. [Run sync](/docs/getting-started/run-sync) — polling, events, and React Query invalidation.

For a runnable fullstack example, see `examples/inventory-json-polling`.
