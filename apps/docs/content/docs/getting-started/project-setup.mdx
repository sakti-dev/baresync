# Project Setup

Start from an empty directory. You will create a Bun workspace with two apps and one shared package.

## Create the root workspace

```bash
mkdir my-inventory && cd my-inventory
bun init -y
```

Edit `package.json` to add workspaces and scripts:

```json
{
  "name": "my-inventory",
  "private": true,
  "type": "module",
  "workspaces": [
    "apps/*",
    "packages/*"
  ],
  "scripts": {
    "generate": "bun run --cwd packages/sync-contract generate",
    "dev": "bunx concurrently --kill-others-on-fail \"bun run --cwd apps/server dev\" \"bun run --cwd apps/app tauri:dev\""
  },
  "devDependencies": {
    "concurrently": "^9.2.1"
  }
}
```

## Scaffold the Tauri app

```bash
bun create tauri-app apps/app --template react-ts
cd apps/app
```

Then add the dependencies your app needs:

```bash
bun add baresync drizzle-orm @tanstack/react-query
bun add -d @tailwindcss/vite tailwindcss
```

If Baresync is not published yet, use a local path instead:

```bash
bun add baresync@file:../../../path/to/packages/baresync
```

Your `apps/app/package.json` should have a `tauri:dev` script:

```json
{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "tauri:dev": "tauri dev",
    "tauri:build": "tauri build"
  }
}
```

## Scaffold the Hono server

From the project root:

```bash
bun create hono apps/server
cd apps/server
```

Then add dependencies:

```bash
bun add baresync drizzle-orm
```

Again, use a local path if Baresync is not published yet.

## Verify the structure

Your project should now look like this:

```txt
my-inventory/
├── package.json
├── apps/
│   ├── app/         # Tauri + React app
│   └── server/      # Hono server
```
