# Tauri Plugin Host Tests

If you customize the Tauri plugin — register extra commands, change event handling, or modify polling behavior — you need to test those changes against a real SQLite database with mock HTTP and event sinks.

## When you need this

Most apps use the plugin as-is. You only need this page if you:

- Add or modify Tauri commands
- Customize event emission
- Change polling lifecycle behavior
- Contribute to the plugin crate

## Test harness

Create a `PluginState` with a real SQLite pool, recording transport, and recording event sink:

```rust
use tauri_plugin_baresync::commands::{
    PluginEvent, PluginEventSink, PluginState,
};
use baresync_core::config::SyncEngineConfig;
use baresync_core::engine::SyncContractTables;
use baresync_core::http::{SyncHttpTransport, SyncTransportFuture};
use sqlx::sqlite::{SqliteConnectOptions, SqlitePoolOptions};
use std::str::FromStr;
use std::sync::atomic::AtomicBool;
use std::sync::Arc;
use tokio::sync::Notify;

// Capture events emitted by the plugin
#[derive(Clone, Default)]
struct RecordingEventSink {
    events: Arc<std::sync::Mutex<Vec<String>>>,
}

impl PluginEventSink for RecordingEventSink {
    fn emit(&self, event: PluginEvent) {
        self.events.lock().unwrap().push(match event {
            PluginEvent::DataChanged => "baresync://data-changed".to_string(),
            PluginEvent::SyncStatusChanged => "baresync://sync-status-changed".to_string(),
        });
    }
}

async fn create_harness() -> (PluginState, RecordingEventSink) {
    let db_path = std::env::temp_dir().join(format!(
        "baresync-test-{}.db",
        std::time::SystemTime::now()
            .duration_since(std::time::UNIX_EPOCH)
            .unwrap()
            .as_nanos()
    ));
    let options = SqliteConnectOptions::from_str(&format!("sqlite:{}", db_path.display()))
        .unwrap()
        .create_if_missing(true)
        .pragma("foreign_keys", "ON");
    let pool = SqlitePoolOptions::new()
        .max_connections(1)
        .connect_with(options)
        .await
        .unwrap();

    let event_sink = RecordingEventSink::default();

    let state = PluginState {
        pool: Arc::new(pool),
        sync_config: SyncEngineConfig {
            api_url: "http://127.0.0.1:9/sync".to_string(),
            scope_id: "scope-1".to_string(),
            transport: Arc::new(RecordingTransport::new(/* mock responses */)),
            ..Default::default()
        },
        contract_tables: SyncContractTables {
            upsert_order: vec!["items".into()],
            delete_order: vec!["items".into()],
            local_only_columns: vec![],
        },
        db_path,
        embedded_migrations: Arc::new(vec![
            EmbeddedMigration {
                name: "0001_test",
                sql: "CREATE TABLE IF NOT EXISTS items (id TEXT PRIMARY KEY, name TEXT NOT NULL, ...)",
            },
        ]),
        migrations_dir: None,
        poll_notify: Arc::new(Notify::new()),
        sync_in_progress: Arc::new(AtomicBool::new(false)),
        poll_control_tx: tokio::sync::Mutex::new(None),
        poll_task_handle: tokio::sync::Mutex::new(None),
        poll_state: Arc::new(tokio::sync::Mutex::new(PollingState {
            paused: false,
            last_sync_at: None,
        })),
        poll_interval_secs: 30,
        poll_on_background: false,
        event_sink: Arc::new(event_sink.clone()),
    };

    (state, event_sink)
}
```

## Testing commands

### SQL execution

```rust
#[tokio::test]
async fn run_sql_executes_and_returns_rows() {
    let (state, _sink) = create_harness().await;
    run_migrations_with_state(&state).await.unwrap();

    run_sql_with_state(&state, SqlQuery {
        sql: "INSERT INTO items (id, name) VALUES ('item-1', 'Coffee')".into(),
        params: vec![],
        method: "run".into(),
    }).await.unwrap();

    let rows = run_sql_with_state(&state, SqlQuery {
        sql: "SELECT id, name FROM items".into(),
        params: vec![],
        method: "all".into(),
    }).await.unwrap();

    assert_eq!(rows.len(), 1);
    assert_eq!(rows[0].columns, vec!["id", "name"]);
    assert_eq!(rows[0].values, vec![Value::String("item-1".into()), Value::String("Coffee".into())]);
}
```

### Events emitted on writes

```rust
#[tokio::test]
async fn writes_emit_data_changed() {
    let (state, sink) = create_harness().await;
    run_migrations_with_state(&state).await.unwrap();

    run_sql_with_state(&state, SqlQuery {
        sql: "INSERT INTO items (id, name) VALUES ('item-1', 'Coffee')".into(),
        params: vec![],
        method: "run".into(),
    }).await.unwrap();

    let events = sink.events.lock().unwrap().clone();
    assert_eq!(events, vec!["baresync://data-changed"]);
}
```

### Reads don't emit events

```rust
#[tokio::test]
async fn reads_do_not_emit_data_changed() {
    let (state, sink) = create_harness().await;
    run_migrations_with_state(&state).await.unwrap();

    run_sql_with_state(&state, SqlQuery {
        sql: "SELECT * FROM items".into(),
        params: vec![],
        method: "all".into(),
    }).await.unwrap();

    let events = sink.events.lock().unwrap().clone();
    assert!(events.is_empty());
}
```

## Testing sync commands

### sync_now with mock transport

```rust
#[tokio::test]
async fn sync_now_uses_engine_with_configured_transport() {
    let transport = RecordingTransport::new(
        push_response_with_table_ack(),
        status_response(false),
        pull_response_with_rows(vec![]),
    );
    let (state, sink) = create_harness_with_transport(Arc::new(transport)).await;
    run_migrations_with_state(&state).await.unwrap();

    let result = sync_now_with_state(&state, "scope-1".into()).await.unwrap();

    assert_eq!(result.mode, SyncNowMode::NoOp);
    let events = sink.events.lock().unwrap().clone();
    assert!(events.contains(&"baresync://sync-status-changed".to_string()));
}
```

## Testing polling

### Polling lifecycle

```rust
#[tokio::test]
async fn polling_starts_stops_and_reports_status() {
    let (state, _sink) = create_harness().await;

    start_polling_with_state(&state, "scope-1".into()).await.unwrap();

    let status = get_polling_status_with_state(&state).await.unwrap();
    assert!(status.running);

    stop_polling_with_state(&state).await.unwrap();

    let status = get_polling_status_with_state(&state).await.unwrap();
    assert!(!status.running);
}
```

### Pause and resume

```rust
#[tokio::test]
async fn polling_pauses_and_resumes() {
    let (state, _sink) = create_harness().await;
    start_polling_with_state(&state, "scope-1".into()).await.unwrap();

    pause_polling_with_state(&state).await.unwrap();
    let status = get_polling_status_with_state(&state).await.unwrap();
    assert!(status.paused);

    resume_polling_with_state(&state).await.unwrap();
    let status = get_polling_status_with_state(&state).await.unwrap();
    assert!(!status.paused);
}
```

## Running plugin tests

```bash
cargo test -p tauri-plugin-baresync          # all plugin tests
cargo test -p tauri-plugin-baresync commands  # just command tests
cargo test -p tauri-plugin-baresync simulation  # just lifecycle tests
```
