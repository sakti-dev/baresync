## Package structure

```txt
baresync/
├── packages/baresync/src/       TypeScript package
│   ├── tauri/client.ts          SyncClient (JS → IPC → Rust)
│   ├── db/drizzle-proxy.ts      createTauriDrizzleDatabase
│   ├── schema/                  localSyncColumns, apiSyncColumns, tables
│   ├── generator/               defineSyncConfig, generate, diagnostics
│   ├── server/                  handlers, service, idempotency, chunking
│   └── limits.ts                DEFAULT_MAX_PUSH_ROWS, etc.
├── crates/baresync-core/src/    Rust core library
│   ├── engine.rs                SyncEngine (push, pull, syncNow, fullResync)
│   ├── db.rs                    LocalDatabase, connect, get_db_info
│   ├── migrations.rs            EmbeddedMigration, run_migrations
│   ├── push.rs                  build envelope, upsert, soft delete
│   ├── pull.rs                  apply batch, cursor handling
│   ├── state.rs                 LocalSyncState
│   ├── gc.rs                    run_garbage_collection
│   ├── outbox.rs                count, mark synced, purge
│   ├── cursor.rs                get/set cursor
│   ├── error.rs                 SyncError enum
│   └── http.rs                  SyncHttpTransport trait
└── crates/tauri-plugin-baresync/src/  Tauri plugin
    ├── builder.rs               Builder (configures and builds the plugin)
    ├── commands.rs              #[tauri::command] functions
    ├── polling.rs               polling loop, PollingStatus
    └── config.rs                PluginConfig
```
