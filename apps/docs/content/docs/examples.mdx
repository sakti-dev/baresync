These examples mirror the public package surface.

For a complete fullstack starter, use [`examples/inventory`](https://github.com/sakti-dev/baresync/tree/main/examples/inventory).

The inventory server example includes two repository paths for comparison:

- `apps/server/src/db/primitive/sync-repository.ts` shows the lower-level sync plumbing.
- `apps/server/src/db/drizzle-helper/sync-repository.ts` shows the Drizzle helper-backed version that the app runs by default.

## Local synced schema

Use `localSyncColumns()` for local SQLite tables that the plugin will reconcile.

```ts
import { localSyncColumns } from "baresync/schema";
import { integer, sqliteTable, text } from "drizzle-orm/sqlite-core";

export const categories = sqliteTable("categories", {
  id: text("id").primaryKey(),
  merchantId: text("merchant_id").notNull(),
  name: text("name").notNull(),
  sortOrder: integer("sort_order").notNull().default(0),
  ...localSyncColumns(),
});

export const products = sqliteTable("products", {
  id: text("id").primaryKey(),
  merchantId: text("merchant_id").notNull(),
  categoryId: text("category_id").notNull().references(() => categories.id),
  name: text("name").notNull(),
  priceMinorUnits: integer("price_minor_units").notNull(),
  ...localSyncColumns(),
});
```

## Server row-state schema

Server tables use `apiSyncColumns()` for incremental pull cursors.

```ts
import { apiSyncColumns } from "baresync/schema";
import { integer, sqliteTable, text } from "drizzle-orm/sqlite-core";

export const apiProducts = sqliteTable("products", {
  id: text("id").primaryKey(),
  merchantId: text("merchant_id").notNull(),
  name: text("name").notNull(),
  priceMinorUnits: integer("price_minor_units").notNull(),
  ...apiSyncColumns(),
});
```

## Generate from a config

### JSON config

Use `defineSyncConfig` when you want the standard JSON generation path.

```ts title="sync.config.ts"
import { defineSyncConfig } from "baresync/generator";
import * as apiSyncedSchema from "./src/api-synced-schema";
import * as localSyncedSchema from "./src/local-synced-schema";

export const syncGeneratorConfig = defineSyncConfig({
  apiSyncedSchema,
  localSyncedSchema,
  outputDir: "./generated",
  packageName: "example.sync.v1",
  tables: {
    categories: { scope: "merchant_id" },
    products: { scope: "merchant_id" },
  },
});
```

### Protobuf config

Use `defineProtobufSyncConfig` when you want protobuf workspace artifacts in addition to the JSON outputs.

```ts title="sync.config.ts"
import { defineProtobufSyncConfig } from "baresync/generator";
import * as apiSyncedSchema from "./src/api-synced-schema";
import * as localSyncedSchema from "./src/local-synced-schema";

export const protobufSyncGeneratorConfig = defineProtobufSyncConfig({
  apiSyncedSchema,
  localSyncedSchema,
  outputDir: "./generated/protobuf",
  outputs: {
    proto: "./generated/protobuf/sync.proto",
    runtimeSourceTs: "./generated/protobuf/runtime.ts",
    runtimeTs: "./generated/protobuf/runtime.generated.ts",
    rustSyncMappers: "../../apps/app/src-tauri/src/protobuf_generated.rs",
    syncTs: "./generated/protobuf/sync.generated.ts",
  },
  packageName: "example.sync.v1",
  tables: {
    categories: { scope: "merchant_id" },
    products: { scope: "merchant_id" },
  },
});
```

Export `protobufSyncGeneratorConfig` from the same `sync.config.ts` and let `baresync generate` pick it up automatically.

Run these commands from the directory that contains `sync.config.ts`:

```bash
bunx baresync doctor
bunx baresync generate
```

Generation emits table order and manifest files in `./generated`. Protobuf workspaces also emit the protobuf runtime and mapping artifacts under `./generated/protobuf`.

## Drizzle through Tauri IPC

Use the local plugin bridge for app reads and writes.

```ts
import { createTauriDrizzleDatabase, type InvokeFn } from "baresync/db";
import { invoke } from "@tauri-apps/api/core";
import { categories, products } from "./schema";

export const db = createTauriDrizzleDatabase({
  schema: { categories, products },
  invoke: invoke as unknown as InvokeFn,
});

export const latestProducts = db.select().from(products);
```

## Tauri sync client

The frontend sync client is a small wrapper over plugin command names.

```ts
import { createSyncClient } from "baresync/tauri";
import { invoke } from "@tauri-apps/api/core";

const sync = createSyncClient({
  apiUrl: "https://api.example.com",
  encoding: "json",
  scopeId: "merchant-1",
  invoke,
});

await sync.syncNow();
await sync.push();
await sync.pull();
await sync.fullResync();

const state = await sync.getState();
```

`apiUrl` and `encoding` are part of the JS config shape, but the current command wrapper only sends `scopeId` to the plugin. Configure API URL and encoding when registering the Rust plugin.

## Plugin registration

Register the plugin with explicit config so the frontend, Rust engine, and backend agree on the same contract.

```rust
use tauri_plugin_baresync::builder::Builder as BaresyncBuilder;

fn sync_tables() -> baresync_core::engine::SyncContractTables {
    baresync_core::engine::SyncContractTables {
        upsert_order: vec!["categories".to_string(), "products".to_string()],
        delete_order: vec!["products".to_string(), "categories".to_string()],
        local_only_columns: vec!["is_synced".to_string()],
    }
}

tauri::Builder::default()
    .plugin(
        BaresyncBuilder::new()
            .api_base_url("https://api.example.com")
            .encoding("json")
            .max_push_bytes(2 * 1024 * 1024)
            .max_push_rows(2000)
            .db_path("baresync.db")
            .contract_tables(sync_tables())
            .build(),
    );
```

## Server handler factory

Use low-level primitives when your backend owns validation, authorization, tenancy, and persistence details.

```ts
import {
  createSyncPullHandler,
  createSyncPushHandler,
  createSyncStatusHandler,
} from "baresync/server";
import { SYNC_UPSERT_ORDER } from "./generated/sync-table-order";
import { serverDb } from "./server-db";

const resolveScope = async ({ context, scopeId }) => {
  const scope = await authorizeScope(context.session, scopeId);
  if (!scope) {
    return { ok: false, status: 403, body: { error: "forbidden" } };
  }
  return { ok: true, scope };
};

export const push = createSyncPushHandler({
  applyPushChanges: async ({ changes, scope, syncUpdatedAt }) => {
    return pushTablesWithAppOwnedOperations({
      changes,
      scope,
      syncUpdatedAt,
    });
  },
  encoding: "json",
  idempotency: { db: serverDb },
  resolveScope,
  upsertOrder: SYNC_UPSERT_ORDER,
});

export const pull = createSyncPullHandler({
  encoding: "json",
  limit: 1000,
  loadPullChanges: async ({ cursor, scope, tables, limit }) => {
    return loadChangedRows({ cursor, scope, tables, limit });
  },
  resolveScope,
});

export const status = createSyncStatusHandler({
  encoding: "json",
  loadSyncStatus: async ({ cursor, scope }) => {
    return loadStatus({ cursor, scope });
  },
  resolveScope,
});
```

The idempotency guard expects the `sync_batch_requests` table exported as `syncBatchRequests` and `syncServerSchema`.

## Server primitives

If the factory is too much structure, use the primitives directly.

```ts
import {
  createIdempotencyGuard,
  decodeSyncRequest,
  encodeSyncResponse,
  orderPushChanges,
  validatePushEnvelope,
} from "baresync/server";

export async function pushRoute(request: Request, context: Context) {
  const idempotency = createIdempotencyGuard({ db: context.db });
  const decoded = await decodeSyncRequest({
    encoding: "json",
    kind: "push",
    request,
  });

  validatePushEnvelope(decoded, {
    maxBytes: 2 * 1024 * 1024,
    maxRows: 2000,
  });

  const scope = await resolveScope({
    scopeId: decoded.body.scopeId,
    session: context.session,
  });

  if (!scope.ok) {
    return Response.json(scope.body, { status: scope.status });
  }

  const result = await idempotency.run(
    {
      clientId: decoded.body.clientId,
      idempotencyKey: decoded.body.idempotencyKey,
      requestHash: decoded.requestHash,
    },
    async () => {
      const orderedChanges = orderPushChanges({
        changes: decoded.body.tables,
        order: ["categories", "products"],
      });

      return await pushTablesWithAppOwnedOperations({
        changes: orderedChanges,
        scope: scope.scope,
        syncUpdatedAt: Date.now(),
      });
    },
  );

  return encodeSyncResponse({
    body: result.result,
    encoding: "json",
    kind: "push",
  });
}
```

## Protobuf encoding

Generate protobuf workspace artifacts when you need the protobuf transport path.

```ts
import { generateProtobufWorkspaceArtifacts } from "baresync/generator";
import { protobufSyncGeneratorConfig } from "./sync.config";

generateProtobufWorkspaceArtifacts(protobufSyncGeneratorConfig);
```

Start with JSON while integrating. Move to protobuf after the contract, handler behavior, and fixture smoke path are already stable.
