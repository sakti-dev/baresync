# Examples

If you are starting a new app, use `create-baresync` first. The examples below are for reference, comparison, and manual setup.

## inventory-json-polling

The canonical fullstack starter. A single-scope inventory app with:

- Tauri desktop client (React + React Query)
- Hono backend server
- Shared sync contract package
- Build-time migration discovery
- Automatic polling and event-driven cache invalidation

```txt
examples/inventory-json-polling/
├── apps/app/          # Tauri + React
├── apps/server/       # Hono
└── packages/sync-contract/
```

Run it:

```bash
cd examples/inventory-json-polling
bun install
bun run generate
bun run dev
```

The server seeds sample data on first run. The app pulls it on the first sync cycle.
